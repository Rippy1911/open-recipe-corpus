# AI images

AI-generated illustrations of dishes, one folder per dish. Each `1.json` gives the `dish`, its Wikidata `qid` and
`ai_generated: true`. They are CC0 1.0 and are marked as AI-generated in their embedded metadata (IPTC
`trainedAlgorithmicMedia`). They are not photographs of any recipe. The API uses one only when a recipe has no
contributed photo in [`photos/`](../photos/README.md).
